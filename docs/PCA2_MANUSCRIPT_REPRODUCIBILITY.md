# Reproducing the revised PCA-2 manuscript configuration

This page documents the **configuration of the corrected V3 classification code** used in the revised NeuroBridge manuscript. It does not change the original scientific scripts.

## Scientific scope

- Label: **TCGA-GBM vs TCGA-LGG project membership** using already-prepared, matched expression and histology features. This is a research prototype, **not** a patient-facing diagnostic tool.
- Canonical cohort: 686 matched patients (195 TCGA-GBM, 491 TCGA-LGG); 480 train, 103 validation, 103 historically examined fixed-test patients.
- Development analysis: 583 patients in 5-fold cross-validation repeated 3 times, yielding 15 development evaluations. Variance filtering, scaling and PCA are fitted within the appropriate training partitions.
- Direct molecular representation: **PCA-2** with `pca_dim: 2`; `topvar: 5000` and `img_to_mol: ridge`. The supervised MLP still has a 64-dimensional latent output; CTransPath+MLP fusion still has 832 dimensions.
- PCA-2 was investigated **after** earlier PCA-128 results; the model choice and 103-person fixed-test evaluation are **retrospective**. This is not an untouched prospective test, and no external GBM/LGG binary validation has been demonstrated.
- All 33 development tissue-source sites were exclusive to one cohort label. Group-held-out site CV is a sensitivity analysis, but cannot disentangle disease and site effects when no site contains both labels.

## Installation and execution

Use the README to install the CLI. This repository intentionally does **not** distribute patient data, raw whole-slide images, precomputed embeddings, or trained weights.

```bash
cp configs/manuscript_pca2.yaml my-pca2-study.yaml
# Edit your private local copy: project, split_csv, and device as appropriate.
# The prepared dataset must follow the structure in docs/REPRODUCIBILITY.md.
neurobridge validate --config my-pca2-study.yaml --stage classification
neurobridge run --config my-pca2-study.yaml --stage classification
```

Every analysis must use a fresh `run_id`, and results appear under `PROJECT/results/corrected_v3/RUN_ID/`. For an approved local source layout, update `split_csv` in your private configuration. **Do not add patient files, actual local paths, or results to this repository.**

## What this does and does not reproduce

- The `classification` stage recomputes the corrected feature-level classification and missing-modality evaluation, not raw WSI or sequencing preprocessing.
- The `biology` stage runs a separate molecular-target analysis and may use the original methodology independent of PCA-2. Its existing figure/report values are not automatically recomputed by a classification-only run.
- The `external` stage **verifies historical external output files**; it does not refit CPTAC or Gene2Morph models.
- The synthetic `neurobridge demo` uses different dimensions and toy data and must never be compared with manuscript metrics.
- Some scientific output identifiers use the historical literal string `molecular_pca128` even when the manifest verifies PCA dimension 2. This is a **legacy display identifier**, not proof of PCA-128 fitting. Verify the manifest's recorded `pca_dim` before relabeling plots for publication.

## Previously reported revised manuscript results (historical; not shipped)

The following values summarize the earlier PCA-2 retrospective analysis; they are **not** generated by this repository's synthetic demo:

| Representation | Development CV balanced accuracy, mean (SD) | Historical fixed-test balanced accuracy |
| --- | --- | --- |
| Direct molecular PCA-2 | 96.13% (SD 1.80%) | 94.15% |
| Supervised molecular MLP latent-64 | 96.24% (SD 1.29%) | 95.88% |
| CTransPath + MLP latent-64 | 96.85% (SD 1.71%) | 98.28% |

These are descriptive within-cohort results and should not be interpreted as externally validated clinical performance. More details and the original evidence files are maintained separately from this public source-only code release.

`configs/example.yaml` uses `pca_dim: 128`, reflecting earlier analyses. The revised manuscript's primary PCA setting is 2, as in `configs/manuscript_pca2.yaml`. Retain the historical configuration for traceability; do **not** rewrite historical outputs or source code to disguise which setting produced each result.
